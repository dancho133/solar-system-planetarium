# Design System — Солнечная система (интерактивный планетарий)

## Product Context
- **What this is:** интерактивная 3D-модель Солнце—Земля—Луна на Three.js, один HTML-файл, зависимости только через CDN (Three.js).
- **Who it's for:** OSS-сообщество и исследователи/обучающиеся; код — читаемый референс.
- **Space:** веб-визуализации космоса (NASA Eyes, Solar System Scope, three.js examples).
- **Project type:** полноэкранная интерактивная WebGL-сцена с минимальным HUD.
- **Memorable thing:** «живой планетарий» — свет, звёзды, течение времени. Вся красота в сцене, интерфейс тихий.

## Aesthetic Direction
- **Direction:** «Тихий планетарий» — диегетическая сцена несёт всё впечатление; HUD как приборная панель обсерватории.
- **Decoration level:** minimal. Ноль декоративных элементов вне 3D-сцены. Свечение короны Солнца — объект сцены (диегетический), не UI-декор.
- **Mood:** спокойное благоговение; инструмент, который показывает, а не развлекает.

## Typography
Ограничение проекта: один файл, внешние зависимости — только Three.js CDN → веб-шрифты запрещены.
- **UI/text:** системный стек `system-ui, 'Segoe UI', Roboto, sans-serif`. Заголовок 16px/600, обычный регистр, без letterspaced-caps костюма.
- **Data:** `ui-monospace, 'Cascadia Mono', Consolas, monospace` — строго для данных: счётчик суток, скорость времени. Не как «техно-костюм» для подписей.
- **Scale:** 16 (заголовок) / 14 (базовый) / 12.5–13 (подписи, кнопки) / 12 (данные).

## Color
- **Approach:** restrained. Один акцент, цвет редок и осмыслен.
- **Background:** `#04060a` — нейтральный, чуть тёплый космос. Никакого синe-indigo дефолта.
- **Ink:** `#e9edf2`; приглушённый: `#8b93a1`.
- **Hairline:** `rgba(255,255,255,.12)`; панель: `rgba(10,13,18,.78)` без backdrop-blur (botched glass не рискуем).
- **Accent:** тональный янтарь `#d9a05b` — цвет солнечного света. Только активные состояния, ползунок, строка факта. Запрещены: сине-фиолетовые градиенты, свечения под кнопками, saturated-попы.
- **Scene palette:** Солнце #ffb43c (эмиссия), Земля океан #0e2f56–#123a66 + земляные зелёно-охристые, Луна нейтрально-серая, звёзды белые/тёплые/голубоватые точки.

## Spacing
- **Base unit:** 8px. Панель управления: padding 9×14, зазоры 10–14.
- **Density:** компактная; HUD не спорит со сценой за площадь.

## Layout
- Полноэкранный canvas. Заголовок + подсказка + факт — верхний левый угол прямо на космосе (тонкая тень вместо карточки-фона). Управление — узкая панель внизу по центру. Центр экрана всегда принадлежит сцене.
- **Radius:** кнопки/панель 8–10px. Никаких пилюль.

## Motion
- **Approach:** minimal-functional.
- Переключение масштаба: экспоненциальная интерполяция параметров (~1 c, `k=1−e^(−3dt)`), без скачков.
- Слежение камеры: бесшовный перенос дельты цели.
- Hover: только сдвиг цвета фона/рамки. Никаких lift, подчёркиваний, glow, boop-прыжков.
- Контент видим по умолчанию; тост — транзиентная обратная связь, не гейт контента.

## 2026-08-24 — Visual fidelity and controls update
- Добавлены два слоя звёзд: мягкие point-sprites для глубины и редкие более яркие звёзды для ощущения оптики, при этом фон оставлен почти чёрным.
- Планеты переведены на `MeshStandardMaterial` с roughness и bump-рельефом; NASA-карты используются как реальные цветовые карты с процедурным fallback.
- Земля получила отдельный слой ночных огней, который появляется на ночной стороне и вращается синхронно с поверхностью.
- Орбиты стали тоньше и плотнее по сегментации, их можно скрывать отдельным переключателем; подписи также отключаются независимо.
- Добавлен селектор «Наблюдать» и amber-кольцо текущего фокуса. Выбор тела теперь мягко приближает камеру к полезной дистанции.
- Интерфейс остался в одном HTML-файле и без веб-шрифтов/antd-зависимости, чтобы сохранить исходное ограничение проекта: внешняя зависимость — только Three.js CDN.
