# Солнечная система — интерактивный планетарий

Однофайловая WebGL-сцена на Three.js для спокойного, но выразительного наблюдения за Солнцем, планетами, Луной, галилеевыми спутниками и поясом астероидов.

## Что внутри

Сцена использует физически ориентированные материалы, процедурный fallback для текстур, NASA-карты для доступных планет, bump-рельеф, ночные огни Земли, облачный слой, мягкую солнечную корону, многослойное звёздное поле и отдельные орбитальные линии. В видимом масштабе тела увеличены художественно, чтобы их можно было рассматривать; режим «Реальный» возвращает честные отношения размеров и расстояний.

HUD остаётся минимальным и не закрывает сцену. Доступны пауза, скорость времени, два режима масштаба, выбор тела для наблюдения, переключатели орбит и подписей, сброс камеры, клик по объектам, плавный follow-режим и клавиши Space/Esc.

## Запуск

Открой проект через локальный HTTP-сервер, так как браузеры могут блокировать ES-модули и загрузку CDN при открытии HTML напрямую через `file://`.

```bash
python3 -m http.server 8000
```

После этого открой `http://localhost:8000/index.html`.

## Файлы

| Файл | Назначение |

## Источники текстур

Для карт планет используется открытый набор [NASA 3D Resources](https://github.com/nasa/NASA-3D-Resources). Если сеть или отдельная карта недоступна, сцена остаётся рабочей благодаря процедурным текстурам.
